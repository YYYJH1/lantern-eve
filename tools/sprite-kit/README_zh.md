# 精灵工具包

小镇地图上的人、地方和道具，游戏页面不在运行时现画。这个工具包在构建时把它们渲染一次。它用的是一个自己写的小型 WebGL2 光线步进器，靠有向距离场、卡通着色和墨线来画，不用任何库，也没有模型文件。每个精灵的每一帧都烘焙进两张图集，再配一份清单。游戏页面只管把这些帧画出来。

```
node tools/sprite-kit/bake.mjs [--jobs 4] [--only char.li_da,place.bridge] [--scales 1,2] [--px 56] [--out out] [--kmax N]
```

它要用 Node 22，以及 `web/` 里的 Playwright 和它的 Chromium。脚本去 `../../web` 找 Playwright，`KIT_PLAYWRIGHT_FROM` 可以指向另一个 `web/` 目录。软件 WebGL 就够用，有显卡只是烘焙得快些。`--jobs` 是同时烘焙的浏览器个数，`--scales` 是要做哪几种倍率的图集（`1,2`），`--px` 是 1 倍图里一个世界单位占几个像素。`--only` 只烘焙这些 id 或 id 前缀的精灵，`--kmax N` 只烘焙每个动画的前 N 帧。带了这两个选项中的任何一个，写出的清单都不完整，只能拿来看，不能拿去发布。最重的帧最先烘焙，每一帧按 2 倍渲染时要占几 GB 内存，所以每多一个任务，就要多占这么多内存。

## 它写出什么

`out/` 里有 `atlas-1x.webp` 和 2 倍图集，两种都是无损的。2 倍图集一般是 `atlas-2x.webp`，比 4,096 像素高时拆成 `atlas-2x-1.webp` 和 `atlas-2x-2.webp`。另外还有 `manifest.json` 和两张给人看的图。一张是 `contact-sheet.png`，画出每个精灵和它的锚点、占地。另一张是 `walk4.gif`。这次运行的耗时写进 `bake.mjs` 旁边的 `bake-report.json`。`out/` 和这份报告都不进 git。

清单（`schema: lantern-eve/sprite-kit@1`）就是工具包和页面之间的全部约定。清单里写着相机和单位，一个格子在屏幕上宽 32 像素、深 25.22 像素，每高一个世界单位就往上挪 34.48 像素。清单里还有图集文件，以及每个精灵的帧大小、锚点、每一帧在每张图集里的位置，还有摆放这个精灵要知道的东西。

- 人物有 `idle`、`walk` 和 `talk` 三套动画，搬东西的人物还有 `carry`。每套动画有 `down`、`up`、`left`、`right` 四个朝向，各自单独渲染。`walk` 记着一步迈出多少像素。锚点是两脚中间的地面点。工具包给人物表上的二十个人和总管各做了一个小人，另有三个镇上的路人，一男一女一个孩子。谁用哪个小人，写在 `web/src/page/map/sprites.ts` 里。
- 地方有按格子算的占地，锚点在占地西南角的地面上。房子记着两盏门灯挂在哪里。有窗的建筑写明它亮窗的精灵（`lights`，见下文），桥记着人走上桥面时要抬高多少。
- 道具或特效有占地，或者有混合模式。灯笼记着光晕放在哪里。树、长青苔的石堆和杂物堆都是道具，各占一格。

帧大小、锚点和偏移都按 1 倍图的像素算。2 倍图集里是同样的帧，大小是两倍。页面画两种图集时，都按 1 倍的逻辑大小来画。

## 夜里的窗

有窗的建筑还有第二个精灵 `fx.windows.<name>`，它不是把这座建筑再画一遍。它画的是亮着的窗格，以及挂在建筑上的灯笼纸。它用同一个模型，在光线步进器的另一个模式（`uMode 1`）下渲染一次。在这个模式里，窗格是平平的暖色，别的东西都透明，但仍然挡住后面的东西。窗格前面的窗棂还是暗的，所以光是从窗棂缝里透出来的。到了夜里，页面把这个精灵叠在建筑上面，锚点和建筑一样，白天就不画。建筑的清单项用 `lights` 指明它。它自己的清单项用 `spots` 记着各扇窗的位置，写成 `[x, y, w, h]`，从锚点算起，单位是 1 倍图的像素，y 朝下。页面在每扇窗上加一圈柔和的光晕。同一种建筑共用一个亮窗精灵。两座李家宅共用一个，两座周家宅也共用一个。摊位和桥没有亮窗精灵。

## 页面角落里的物件

有四个精灵不是给地图用的，而是给页面角落用的，总管在那里放着办事用的东西。`prop.elder_seal` 是一方石印，印面刻着「族」字，印钮上系着红绳。`prop.notebook` 是一本平放的线装书，签条上写着「见闻簿」，书脊在右边，跟旧书一样。`prop.incense_unlit` 是一只青铜香炉，插着一炷香。`prop.incense_lit` 是同一只香炉，香头亮着，冒出一缕烟。它们和人物、道具走同一条烘焙流程，用同一台相机、同一盏灯，在 1 倍图里高 57 到 71 像素。每一件都立在一个点上，没有占地。两只香炉是同一个模型，所以页面换着用时，锚点对齐，什么都不会挪动。点着的那只在锚点上方多出一缕烟，锚点下方留的空间一样。

页面画它们，就像画清单里别的精灵一样。`frames` 给出图集里的 `[page, x, y]`，`frame` 是 1 倍图的像素大小，`anchor` 是帧里的地面点。

这些物件有自己的着色器程序。`src/shaders/objects.glsl` 里是它们的三个模型、材质和挑模型的代码，`engine.js` 把它编译成名为 `objects` 的程序。这个程序用同一个步进器和同一套人物代码，只是拿这些模型换掉了地方的模型。烘焙其余精灵的那个程序里没有这些模型，它的贴字画布里也没有，所以往工具包里加物件，不会改动图集里已有的任何精灵。印上的字和签条上的字是马善政的轮廓（`src/page/glyphs.js`，由 `tools/fonts/glyph_paths.py` 生成），由 `places.js` 里的 `makeObjectsDecal` 画在它们自己的贴字画布上。

## 比较两次烘焙

```
node tools/sprite-kit/compare.mjs web/public/sprites tools/sprite-kit/out [--partial]
```

它在 Chromium 里解码两个目录里的图集，逐个精灵、逐帧比较像素的每一个字节。它也比较每个精灵的清单项，只是不比各帧的位置，因为加了精灵以后，帧在图集里会挪位置，像素不会变。只有新清单里才有的精灵会列出来，不算错。`--partial` 还允许新清单少一些精灵，给带 `--only` 的烘焙用。比较的内容全都一样时，退出码是 0。

## 美术放在哪里

`web/public/sprites/` 里放着页面要加载的文件，有图集和 `manifest.json`。图集是 `atlas-1x.webp`，2 倍图集一页 4096 像素放不下时，还有 `atlas-2x-1.webp` 和 `atlas-2x-2.webp`。烘焙完以后，先把那里的旧图集删掉，再把新文件从 `out/` 复制过去。

```
rm web/public/sprites/atlas-*.webp
cp tools/sprite-kit/out/atlas-*.webp tools/sprite-kit/out/manifest.json web/public/sprites/
```

页面读清单，不从固定的位置取帧。清单里新加的精灵，只要 `web/src/page/map/sprites.ts` 写明它画的是谁或什么，就不用改代码。

## 烘焙是确定的

源文件和选项一样，写出的文件就逐字节一样。浏览器哪个先做完都没关系，因为打包之前会先给帧排好序。Chromium 加进图片的颜色配置也剪掉了，所以不管用什么加载，看到的颜色都一样。每次运行都会变的耗时，不写进 `out/`。所以 `web/public/sprites/` 下这四个文件（几张图集和 `manifest.json`）有了变化，一定是源文件或选项变了。

## 源文件

- `bake.mjs` 启动浏览器，把帧分给它们，再打包图集、写出文件。
- `src/shaders/` 是 GLSL。`march.glsl` 是光线步进器，`figures.glsl` 画人，`places.glsl` 画茶馆、两家的宅子、栈桥、石桥、竹竿堆、灯笼和垂柳，`town.glsl` 画其余的建筑。普通房子共用一个主体，每座建筑另有一个函数，写它自己的样子。`trees.glsl` 画树、石堆和杂物堆。`dispatch.glsl` 决定一个地方用哪个模型，并给出地方材质的反照率，还有夜里的灯光。`common.glsl` 是它们共用的函数，`post.glsl` 画墨线，做最后一遍处理。
- `src/shaders/objects.glsl` 是页面角落物件的程序，`compare.mjs` 比较两次烘焙。
- `src/page/` 在浏览器页面里跑。`config.js` 管单位、相机、光照和调色板，`engine.js` 是 WebGL2 引擎，`catalog.js` 写着人物和各自的动画。`places.js` 写着地方和道具，以及它们的占地（取自 `content/maps/bridge_town.yaml`），还有据此做出的亮窗。`bake.js` 烘焙一帧，`compose.js` 裁剪并打包各帧，还找出夜里亮窗的位置，`gif.js` 做预览，`glyphs.js` 存着印上和签条上那几个字的轮廓。
