# Ink UI

These Python scripts use the standard library to generate the paper borders and brush marks for the web client. Paper borders are nine-slice images. Ticks, circles, tallies and seals are SVG paths.

```bash
uv run python tools/ink_ui/paper.py     # web/public/ui/paper/: the edges and index.json
uv run python tools/ink_ui/marks.py     # web/src/page/ui/marks.ts (--check: fail if it is not up to date)
```

## Paper edges

`paper.py` draws the rough cut and the inner ink line at 1x and 2x so large sheets need no runtime filter. The day palettes pair off-white paper (荼白, #f3f9f1) with black (乌黑, #392f41) or ink grey (墨灰, #758a99). The lamplight palette pairs ivory paper (牙色, #eedeb0) with ink grey. Use `slip` for tags and plaques, and `page` for larger sheets such as the ledger and notebook.

| Grade | Slice | Band | File at 1x | File at 2x |
|---|---|---|---|---|
| slip | 12 | 64 | 88 by 88 px, about 3 KB | 176 by 176 px, about 6 KB |
| page | 20 | 160 | 200 by 200 px, about 7 KB | 400 by 400 px, about 17 KB |

Find the slice, palette and file names in `index.json`. Output follows `<grade>-<palette>-<scale>x.png`, with `day-ink`, `day-grey` and `night` palettes. Each square has four corners and four edge bands. The shape along each band repeats so the edges meet without a seam. The `fill` option stretches the flat centre across the sheet. The script renders the same edge again at 2x.

```css
.sheet { border-image: url("/ui/paper/page-day-ink-1x.png") 20 fill / 20px round; }
@media (min-resolution: 2dppx) {
  .sheet { border-image-source: url("/ui/paper/page-day-ink-2x.png"); border-image-slice: 40 fill; }
}
```

When switching to the 2x image, double `border-image-slice` and keep the CSS border width. Add a separate background if the sheet needs paper grain.

## Brush marks

`marks.py` writes the path data to `web/src/page/ui/marks.ts`. A brush stroke starts with pressure, thickens through the middle and narrows at the end. The outline wavers slightly, and the client can fill it with the ink or red of the current theme.

| Export | What it is |
|---|---|
| `TICKS` | the tick of a line that is done, three of them |
| `CIRCLES` | `round`, `wide` and `long`: a circle drawn by hand round a word or a phrase |
| `STRIKES`, `STRIKE_LINES` | a short stroke that strikes a number out, and a long one that strikes a line through |
| `TALLY`, `tally(n)`, `tallies(n)` | the strokes of 正 in the order they are written, one to five, and the tally of any number |
| `UNDERLINES` | the underline of a word to act on |
| `SEALS` | the seals `done` (办妥) and `delivered` (送到), each `wide` and `square`; one path to fill with the even-odd rule |
| `RULES`, `VERTICAL_RULES` | level and plumb ruled lines for a ledger |
| `GLYPHS` | `pause`, `play` and `menu` for the top right |
| `pick(variants, key)` | the same variant for the same key every time |

Use the mark’s `w` and `h` for the SVG view box and fill its `paths` with `currentColor`. To change the length of a stroke, rule or underline while retaining its height, set the new width and `preserveAspectRatio="none"`.

```tsx
import type { Mark } from "./marks.ts";

const Brush = ({ mark, width, height, stretch }: { mark: Mark; width?: number; height?: number; stretch?: boolean }) => (
  <svg viewBox={`0 0 ${mark.w} ${mark.h}`} width={width ?? mark.w} height={height ?? mark.h} fill="currentColor"
       fill-rule={mark.evenodd ? "evenodd" : undefined} preserveAspectRatio={stretch ? "none" : undefined} aria-hidden="true">
    {mark.paths.map((d) => <path d={d} />)}
  </svg>
);
```

The seals use Ma Shan Zheng glyph outlines from `seal_glyphs.json`, generated by `tools/fonts/glyph_paths.py`. The filled path leaves the characters and a few specks cut out of a slightly tilted block with a thin frame. Fill it with rouge by day or lamplight red at night.
