Web client网页客户端

Both hosts serve the same page. PixiJS draws the map and Preact shows the controls. The page reads game frames and sends back player actions. 两种宿主共用一个页面。PixiJS 画地图，Preact 显示控件。页面接收游戏帧，把玩家的操作发给宿主。

Browser host浏览器宿主

A Web Worker runs the core in Pyodide and saves games in IndexedDB. If the player connects a model, the worker sends requests directly to the selected provider. Web Worker 用 Pyodide 跑核心，把存档写入 IndexedDB。玩家接入模型后，请求从 worker 直接发给所选服务。

Server host服务端宿主

lantern-eve play runs the core under CPython and asyncio, one session per game, with frames over a WebSocket. Model calls go to the providers of a provider file, or to a mock. lantern-eve play 用 CPython 和 asyncio 跑核心，每局开一个会话，帧经 WebSocket 发给页面。模型调用发往提供方文件里的服务，或者交给 mock。

lantern_core

Both hosts call this Python state machine. Each tick takes JSON inputs and returns a frame, events and any model requests. The same inputs produce the same state hash in both runtimes. 两种宿主调用同一份 Python 状态机。每拍传入 JSON，拿回游戏帧、事件和模型请求。输入相同，两边算出的状态哈希就相同。

Recording录像

The seed and the config, every input the core applied with its tick, and the state hash every 100 ticks. Both hosts write the same format, and lantern_core.replay rebuilds either one under CPython as it stands. 每份录像存着种子和配置，还有核心用过的每条输入，每条都记着是第几拍用的。另外每 100 拍记一次状态哈希。两种宿主写同一种格式，哪一份都能由 lantern_core.replay 在 CPython 下原样重建。
