# README 配图

两份 README 里的配图放在 `docs/assets/`，都由这个文件夹里的脚本做出来。脚本要用 Node 22、ffmpeg 和一个无头 Chromium（「headless shell」版），不给项目添任何包。

```
export CHROME_BIN=/path/to/chrome-headless-shell
```

没设 `CHROME_BIN` 时，脚本去 Playwright 的浏览器目录里找无头 shell，就是 `npx playwright install chromium` 装上的那个。设了 `PLAYWRIGHT_BROWSERS_PATH` 就去那里找，没设就找 `~/.cache/ms-playwright`（只限 Linux）。浏览器用 `--incognito` 启动，配置目录和临时文件都放在 `--tmp` 指定的目录里，不指定就放在系统的临时目录。图里的中文用 Noto Sans CJK SC 显示，所以要装上这款字体。ffmpeg 从 `PATH` 里找，也可以用变量 `FFMPEG` 指定。

## 插图

`figures/` 里每张插图一个 HTML 文件，有 `banner` 和 `architecture` 两张。每张插图是一张圆角卡片。`figures.css` 把颜色定义成变量，浅色和深色主题各一套。每段文字都写了两遍，一遍在 `<span class="en">` 里，一遍在 `<span class="zh">` 里，所以一份源文件能出四张图。`connect.js` 画方框之间的箭头。标题用的两款字体，就是游戏页面放在 `web/public/fonts` 里的那两款。

```
node tools/readme_assets/build.mjs
```

它按两倍的像素比写出 `docs/assets/<figure>-<en|zh>-<light|dark>.png`，每张图用 256 色的调色板。`--only banner`、`--lang zh`、`--theme dark`、`--colors N`（0 表示保留浏览器给的真彩色 PNG）、`--out DIR` 和 `--tmp DIR` 用来缩小范围，或者换个地方输出。PNG 超过 400 KiB 就报错。想在浏览器里看一张插图，打开 `figures/banner.html?theme=dark&lang=zh`。

## 页面的截图

`capture_page.mjs` 驱动真的游戏页面，也就是网页客户端的测试版，背后是在 Pyodide 里跑的真核心。它在 127.0.0.1 上起一个文件服务，端口由系统挑，服务的就是 `web/dist-e2e`。然后经 Chrome DevTools Protocol 在浏览器里打开页面，再截图。先要有测试版。

```
(cd web && npm ci && npm run build:e2e)
node tools/readme_assets/capture_page.mjs
```

它做四种图，每种都有浅色、深色两个主题和中文、英文两种语言。

- `play-<lang>-<theme>.gif` 是玩家遇到的第一天。页面打开时地址里没写哪一局，所以它先显示开场页，再跑开场页开的那一局。这一局有自己的种子，按下「开始」之前一直停着。动图先是开场页、「这几个人」那一页和族长的第一张卡片。卡片让总管照红签上画了线的那句话去找李老太。总管走到她跟前，谈话的纸带展开。纸带上有四个按钮，旁边是她的名字和身份，还有一排心，以及红签点名的那件事的预览，也就是借竹料。她不肯借，族长的第二张卡片说明为什么，又说下一步去哪。点开心，能看到心背后的说明，能送的小东西也列了出来。总管照着红签上要问的那句，在「追问哪一条」的列表里挑着问，从李老太一路问到茶馆老板娘，再问到周家伙计。随后见闻簿自己翻开。动图先让人物谱露一下面，再翻到族长并排摆好的那两句话。答错时，页面说再想想。对的答案是伙计看见的撑不起镇上传的那句。接着跳到下午，再到傍晚的茶馆。这里有族长的最后一张卡片，有茶馆里能用的动作的小卡，还有见闻簿。比过的那两句话，就从见闻簿里拿出来当众说。在场的人各用自己的话回答，李老太松了口。然后去请李大送竹料，先看预览，他答应了。晚上九点，灯下的「夜里小结」让世界停着，直到它被收起。再跳过一夜，就是第二天早上。《镇报》出来了，接着是「第一天过完了」的卡片，随后镜头移到桥边。竹料在那里堆成一堆，旁边的账簿写着答应了多少、到了多少。「跳」指的是脚本只推进拍数、不截图的那一段。ffmpeg 用全部帧做出一个调色板，再做成 GIF。
- `notebook-<lang>-<theme>.png` 是总管比完那两句话时的见闻簿，一本线装的册子。左页是记下的事，有拿来比的那句话、三个答案、答的结果、「帮我看看」和比过的几对。右页是还空着的讲稿。册子的高度，取页面上方没有带教或提示那一行时的高度。图在纸边里面那道墨线处截下，纸边是手裁的毛边。册子周围的东西都为这张图收了起来，有红签的纸条、谈话的纸带和人物的卡片。册子里的每一行都留着。册子的每一页都比册子高，「翻页」那句话又盖在页脚上，所以脚本像玩家那样把每一页滚到一个位置，使页的上沿和「翻页」那句话都不切断任何一条，不论是一个标题、一段话、列表里的一行，还是一个按钮。左页要能看见答的结果，右页要能看见讲稿的第三个空和它下面的全部说法。符合这些条件的位置不止一个时，脚本挑能看见最多「帮我看看」、比过的几对的标题和比过的那一对的，再取其中最靠上的。页面上有一道横线，要是它在「翻页」那句话的横线上方露出几个像素，脚本就让「翻页」那句话长到刚好盖住它，盖住的只有这道横线，没有字。拍完以后脚本再读一遍每一页的位置，有条目被切断就报错。加上 `--only notebook`，脚本拍完这张就停，不再演后面的一天。
- `ending-<lang>-<theme>.png` 是一个结局里的传话树，来自只有一天的一局。这一局没人操作，一直跑到最后一夜。树上面的标题把这句闲话的头一种说法和最后一种说法摆在一起，而树里只有这一局里真传过的话。要是闲话没传到标题说的那么远，标题末尾的那句话在树里就没有人说过。脚本从页面的数据里读标题和名字下面的话，遇到这样的一局就报错。
- `festival-<lang>-<theme>.png` 是灯会夜里的一刻，来自最后一夜圆满的一局。这一局的目标由核心的测试动作在第一拍就设好了，有召集两家，有竹料和木料，有当众说清真相，有两家和好。之后世界按自己的节奏，走到这一局三天里的最后一夜。演出用的时钟只有脚本会拨，所以图取的是 `--night-at` 指定的那一秒。默认是结束前三秒半。这时镜头已经拉远，整座小镇都在画面里。游灯的队伍从街上穿过小镇，一直排到祠堂前。主灯已经点亮，河灯顺水漂着，这一夜最后那句话用字说出这一局怎么收的场。窗口是 1280×640，正好是小镇的形状。图宽 1760 像素，是两份 README 显示宽度的两倍，这样 256 色也能压在 400 KiB 以内。

图不随机器的快慢变化。页面用 `?until=1` 打开，世界走完第一拍就停住。脚本再用页面自己的暂停和继续消息，一拍一拍地推进世界。宿主收到继续就走一拍，紧跟着的暂停在下一拍到来之前把世界停住。脚本发出的动作，在发出的那一拍生效。核心只取决于种子和每一拍收到的输入，所以同一个构建得出同一局。每次截图之前，脚本先等地图上什么都不动了，再把地图自己的动画时钟定住，把页面的 CSS 动画结束掉。世界在两张图之间是脚本停住的，这时暂停按钮旁边本该写「已暂停」。这是脚本停的，不是游戏停的，所以脚本让页面照常写「进行中」。谈话是例外。总管说话的时候，核心自己把时钟停住，不管脚本对宿主说什么，都不会来新的一拍，所以脚本在谈话里不推进世界。它只在谈话里做事，用话题、选项列表或卡片上的按钮，或者告辞。每做一件事都要花掉几分钟的游戏时间，脚本把这几分钟一拍拍走完，谈话才又把时钟停住。谈话停着世界时，脚本还要推进一拍，就会直接报错，并说明原因。在谈话里，页面保持游戏本来的样子。每次截图前，脚本先放开自己的暂停，暂停按钮旁边写的是「时间停着」。

图里的核心就是 `web/dist-e2e` 里的那一份。核心或页面改了以后，要重新构建测试版，再跑一次脚本。

- `--only gif,notebook,ending,festival`、`--lang en,zh` 和 `--theme light,dark` 选要做哪些图，默认全做。`--seed N` 设结局那一局的种子，默认是 4927，这一局的树里有标题上的两句话。第一天和灯会夜各有自己的种子。`--night-at S` 取灯会夜的某一秒，也可以给一串秒数，这时每张图的文件名里带上它那一秒。
- `--fps` 和 `--width` 设 GIF 的帧率（默认 10）和宽度（默认 880，就是两份 README 显示它的宽度）。GIF 必须小于 `--max-mb`（默认 4），超了脚本就减少颜色数，直到够小。PNG 必须小于 400 KiB。
- `--jobs N` 设同时做几张图（默认 2），每张图用自己的浏览器。
- `--out DIR` 设图放在哪里（默认 `docs/assets`），`--dist DIR` 选用哪一个测试版（默认 `web/dist-e2e`）。`--chrome FILE`、`--tmp DIR` 和 `--keep` 设用哪个浏览器、临时文件放在哪个目录，以及要不要留下临时文件。
- `--help` 列出全部选项。
